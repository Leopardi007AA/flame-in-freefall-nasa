## Rules from the 2026 terms (must respect)
- Video ≤ 30 s or ≤ 7 slides; longer demos are not eligible for Global Judging.
- Everything in English. A video may be spoken in Italian only with English subtitles.
- Slides must show: team name, names of team members, the challenge chosen, an image of the project, the user experience, and how NASA open data made it possible.
- No one under 18 (face, voice or name) in the video or images.
- Host the demo on YouTube / Drive / etc. with a public link: test it in a private window.
- Optional but recommended: request a FortiGuard web filter classification for the app URL (category: web-based application, company name N/A) so judges can open it.
